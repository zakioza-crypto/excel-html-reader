# ExcelをHTMLで読むツール

Excelファイル（.xlsx）をブラウザにドラッグ＆ドロップすると、読みやすい表として表示するツール。単一HTMLファイルで動作し、処理はすべてブラウザ内で完結するため、ファイルが外部に送信されることはありません。

## 主な機能

- シート切り替え
- 見出し行の選択
- 検索・並び替え・数値列の合計と平均
- 概要ダッシュボード（シート一覧サマリ、列ごとの型・空欄率・ユニーク数・最小最大平均・最頻値、空欄・重複行・型混在・外れ値の要注意ポイント表示と該当セルへのジャンプ）
- データチェック（重複・空欄・型混在の検出）
- 横スクロール対策（列固定・列の絞り込み・転置・カード表示）
- 音声読み上げ（Web Speech API）
- HTML・CSVへの書き出し

## 使い方

HTMLファイルをブラウザで開き、Excelファイルを画面にドロップするだけです。サンプルデータも内蔵しています。

## 注意

収録されているサンプルはすべてダミーデータです。
